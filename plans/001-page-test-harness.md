## Why this matters

`src/web/app.js` is the page's XSS boundary: every attacker-controlled GitHub
string (PR titles, branch names, author logins, error text) must enter the DOM
via `textContent` only, and `href`s must be GitHub HTTPS URLs. Today that
boundary is protected only by a one-off browser QA run whose scripts live in
`/tmp` and are not committed — CI runs no page-level test at all, so a future
edit that switches one `textContent` to `innerHTML`, or loosens the href
guard, lands silently. This plan gives the page script a CI-testable unit
suite (jsdom) and commits the mock-GitHub + Playwright smoke harness so the
browser-level checks are reproducible by anyone with the repo.

## Steps

### Step 1: Make `app.js` importable without side effects

`app.js` currently ends with top-level side effects (`refresh();
setInterval(refresh, 60_000);`) and defines functions without exporting them.
Make it an ES module that exports its functions but keeps identical behavior
in the browser:

- Append `export` keywords to the function declarations (`el`, `reasonLabel`,
  `age`, `renderHoist`, `renderSignal`, `renderPrs`, `renderBranches`,
  `render`, `refresh`).
- Move the bootstrap side effects behind an explicit entry check so importing
  the module in jsdom does not fetch or start a timer:

```js
if (typeof document !== "undefined" && document.getElementById("hoist")) {
  refresh();
  setInterval(refresh, 60_000);
}
```

- The page loads it as `<script src="/app.js"></script>` — a classic script,
  not a module. With `export` keywords present it would fail as a classic
  script. Change `src/web/index.html`'s tag to
  `<script type="module" src="/app.js"></script>` (this is the one permitted
  index.html change; behavior is identical for users).

**Verify**: `pnpm build` → exit 0. Then open the page manually once:
`pnpm dev` (with `GITHUB_TOKEN=dummy SHIPCHECK_REPO=octocat/hello` set) and
load `http://127.0.0.1:3000` — it renders normally (the hoist shows and the

### Step 2: Add jsdom unit tests

Add `jsdom` as a devDependency (`pnpm add -D jsdom`). Create
`src/web/app.test.js` — a Vitest file with
`// @vitest-environment jsdom` as its first line (vitest picks this up without
changing `package.json` config). Because `app.js` touches `document` at import
time only via the entry check, set up the DOM in `beforeEach`:

```js
// @vitest-environment jsdom
import { describe, it, expect, beforeEach, vi } from "vitest";
import { render, renderPrs, age, reasonLabel } from "./app.js";

function mount() {
  document.body.innerHTML = `
    <div id="hoist"></div><div id="signal"></div>
    <div id="banner"></div><span id="repo"></span><span id="meta"></span>
    <div id="prs"></div><div id="branches"></div>`;
}
```

Model the test style after `src/status.test.ts`. Write these cases:

1. **Hostile strings never become markup** — build a payload whose PR title is
   `<img src=x onerror=alert(1)>` and whose author and branch names contain
   `<script>`; call `render()` with a valid ok-response; assert
   `document.querySelector("img, script")` is `null` and the title text
   contains the raw string (textContent, not HTML).
2. **URL guard** — a PR whose `url` is `javascript:alert(1)` renders as text
   with the `(link withheld: unexpected URL)` notice and no `<a>` element; a
   PR whose `url` is `https://github.com/o/r/pull/1` renders an `<a>` with
   exactly that `href`.
3. **Whole-response failure** — `render({ ok: false, error: "boom" })` shows
   the banner, clears `#prs`/`#branches`, empties `#repo`, and the signal word
   reads `incomplete`.
4. **Degraded section** — `render` with `prs: { ok: false, error: "e" }` and a
   ok branches section shows the section error paragraph and meta text
   containing `partially unavailable`.
5. **`age()` boundaries** — 30s → `just now`; 90s → `1m ago` (note: 90s is
   1 minute after `Math.floor(90/60)`); 2h → `2h ago`; 25h → `1d ago`.
6. **Unknown reason code degrades visibly** — `reasonLabel("mystery")` starts
   with `unrecognized reason`.

**Verify**: `pnpm test --run src/web` → the new file passes (6+ tests).

### Step 3: Commit the mock-GitHub server

Create `scripts/qa-mock.mjs` with exactly this content (it is the known-good
harness; the only changes from the /tmp original are repo-relative imports
and the port comment):

```js
// Mock GitHub for QA: replaces globalThis.fetch so the server under test
// never touches the network. Modes: hostile (default, attacker-shaped data)
// and broken (every GitHub call throws). GITHUB_TOKEN is a dummy; the checks
// assert it never reaches the DOM.
import { createApp } from "../dist/app.js";
import { loadConfig } from "../dist/config.js";

const mode = process.env.GITHUB_MODE ?? "hostile";
globalThis.fetch = async (input) => {
  if (mode === "broken") throw new TypeError("connect ECONNREFUSED");
  const url = String(input);
  const body = url.includes("/pulls?")
    ? [{
        number: 7,
        title: "Fix <script>alert(1)</script> bug",
        state: "open",
        draft: false,
        html_url: "https://github.com/octocat/hello/pull/7",
        user: { login: "eve" },
        head: { ref: "feat/x", sha: "abc123" },
        base: { ref: "main" },
        updated_at: "2026-09-26T11:00:00Z",
        mergeable: true,
      }]
    : url.includes("check-runs")
      ? { total_count: 1, check_runs: [{ status: "completed", conclusion: "failure" }] }
      : url.includes("/compare/")
        ? { ahead_by: 0, behind_by: 2 }
        : url.includes("/reviews")
          ? []
          : url.includes("/branches")
            ? [
                { name: "main", commit: { sha: "fff" } },
                { name: "old-branch", commit: { sha: "bbb" } },
              ]
            : url.includes("/commits/")
              ? { commit: { commit: { committer: { date: "2026-05-01T10:00:00Z" } } } }
              : { default_branch: "main" };
  return new Response(JSON.stringify(body), {
    status: 200,
    headers: { "content-type": "application/json" },
  });
};

const { serve } = await import(
  "../node_modules/@hono/node-server/dist/index.js"
);
serve({ fetch: createApp(loadConfig()).fetch, port: Number(process.env.PORT) || 3211 });
console.log("mock server up on", mode);
```

Add to `package.json` scripts:

```json
"qa:mock": "pnpm build && node scripts/qa-mock.mjs",
"qa": "python3 scripts/qa.py"
```

**Verify**: `pnpm build && GITHUB_TOKEN=dummy SHIPCHECK_REPO=octocat/hello GITHUB_MODE=hostile PORT=3211 node scripts/qa-mock.mjs &` then
`curl -s localhost:3211/api/status | head -c 200` → JSON containing
`"octocat/hello"`. Kill the background server afterwards.

### Step 4: Commit the Playwright check script

Create `scripts/qa.py` with exactly this content (verbatim from the known-good
harness):

```python
import re
import sys

from playwright.sync_api import sync_playwright

phase = sys.argv[1]
PORT = sys.argv[2]
BASE = f"http://localhost:{PORT}"
results = []


def check(name, ok, detail=""):
    results.append((name, ok, detail))
    print(f"{'PASS' if ok else 'FAIL'} {name} {detail}")


with sync_playwright() as p:
    browser = p.chromium.launch()

    if phase == "render":
        page = browser.new_page()
        dialogs = []
        page.on("dialog", lambda d: (dialogs.append(d.message), d.dismiss()))
        page.goto(BASE)
        page.wait_for_selector("article.fix")
        check("verdict card renders", True)
        title_text = page.locator("article.fix .pr-title").inner_text()
        check(
            "hostile title rendered as text",
            "<script>" in title_text and "alert(1)" in title_text,
            repr(title_text),
        )
        check("no dialog executed from injected script", len(dialogs) == 0, str(dialogs))
        # Inline scripts only: the page's own <script src="/app.js"> is legitimate.
        inline_scripts = page.evaluate(
            """() => [...document.querySelectorAll('script')]
                .filter(s => !s.src && s.textContent.trim().length > 0).length"""
        )
        check("no inline script elements in DOM", inline_scripts == 0, str(inline_scripts))
        signal = page.locator("#signal").inner_text()
        check("signal word is fix", signal.lower() == "needs fixes", signal)
        check(
            "reason labels present",
            page.locator(".reasons li", has_text="checks failing").count() == 1
            and page.locator(".reasons li", has_text="awaiting review").count() == 1,
        )
        row = page.locator("tr", has_text="old-branch").inner_text()
        check("stale branch flagged with primary reason", "behind default" in row, row.replace("\n", " | "))
        check("repo shown", page.locator("#repo").inner_text() == "octocat/hello")
        page.screenshot(path="/tmp/qa-fix.png", full_page=True)

        # The 60s re-poll (clock-controlled).
        page2 = browser.new_page()
        page2.clock.install()
        poll_requests = []
        page2.on("request", lambda r: poll_requests.append(r.url) if "/api/status" in r.url else None)
        page2.goto(BASE)
        page2.wait_for_selector("article")
        initial = len(poll_requests)
        page2.clock.run_for(61_000)
        page2.wait_for_timeout(200)
        after = len(poll_requests)
        check("60s re-poll fired", after >= initial + 1, f"requests before={initial} after={after}")

    elif phase == "degraded":
        page = browser.new_page()
        page.goto(BASE)
        page.wait_for_selector(".banner")
        banner = page.locator(".banner").inner_text()
        check("degraded banner shown", "unavailable" in banner.lower(), banner.replace("\n", " | "))
        content = page.content()
        check("token not rendered", "dummy" not in content and "ghp_" not in content)
        page.screenshot(path="/tmp/qa-degraded.png", full_page=True)

    browser.close()

failed = [r for r in results if not r[1]]
print(f"{phase}: {len(results) - len(failed)}/{len(results)} checks passed")
sys.exit(1 if failed else 0)
```
